# واژه‌نامه

- **Source:** منبعی که آگهی شغلی از آن دریافت می‌شود.
- **Collector:** اتصال‌دهنده اختصاصی یک منبع.
- **Raw record:** payload دریافت‌شده پیش از نرمال‌سازی.
- **Normalized job:** آگهی تبدیل‌شده به schema مشترک.
- **Collection run:** یک نوبت اجرای collector برای یک منبع.
- **Batch:** مجموعه رکوردهای متعلق به یک اجرای مشخص.
- **Deduplication:** تشخیص و مدیریت آگهی‌های تکراری.
- **Idempotency:** اجرای چندباره یک عملیات بدون ایجاد اثر تکراری ناخواسته.
- **Freshness:** میزان تازگی داده نسبت به آخرین مشاهده یا انتشار.
- **Expired:** آگهی‌ای که دیگر فعال یا قابل دسترسی نیست.
- **Reprocessing:** اجرای دوباره pipeline روی داده خام ذخیره‌شده.
- **Canonical URL:** لینک استانداردشده و اصلی آگهی.
