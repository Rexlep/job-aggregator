# مستندات پلتفرم تجمیع آگهی‌های شغلی

این پوشه منبع اصلی تصمیم‌های محصول، معماری و عملیات پلتفرم تجمیع آگهی‌های شغلی است.

## اسناد

- [نیازمندی‌ها](requirements.md): هدف، کاربران و محدوده نسخه اول
- [معماری](architecture.md): اجزای سیستم و مرزهای ماژول‌ها
- [مدل داده](data-model.md): schema مشترک آگهی شغلی و lifecycle آن
- [جمع‌آوری داده](ingestion.md): قرارداد collectorها و pipeline پردازش
- [API](api.md): قرارداد اولیه REST API
- [عملیات](operations.md): محیط‌ها، پایش، خطا و backup
- [نقشه راه](roadmap.md): فازهای پیاده‌سازی و معیار خروج

## اصول پروژه

1. داده خام هر منبع باید قابل بازبینی و بازپردازش باشد.
2. هر collector باید مستقل، قابل تست و قابل اجرای دوباره باشد.
3. پردازش داده باید idempotent باشد.
4. منطق دامنه نباید به یک منبع خاص وابسته شود.
5. قابلیت مشاهده خطاها از ابتدا بخشی از محصول است.
6. ابتدا modular monolith ساخته می‌شود و جداسازی سرویس‌ها فقط بر اساس نیاز واقعی انجام خواهد شد.

## وضعیت سندها

این سندها baseline طراحی هستند و پیش از شروع پیاده‌سازی باید با تصمیم‌های نهایی محصول و منابع داده بازبینی شوند.
