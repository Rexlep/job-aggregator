# نیازمندی‌های محصول

## هدف

ساخت پلتفرمی production-oriented برای دریافت آگهی‌های شغلی از چند منبع، تبدیل آن‌ها به یک مدل مشترک، ذخیره‌سازی، جست‌وجو و نمایش در داشبورد وب.

## کاربران اصلی

### جوینده کار

- جست‌وجوی متنی آگهی‌ها
- فیلتر بر اساس مکان، مهارت، نوع همکاری، سطح شغلی و حقوق
- مشاهده جزئیات آگهی
- رفتن به لینک اصلی آگهی

### مدیر سیستم

- مشاهده وضعیت منابع
- مشاهده اجرای collectorها و خطاها
- اجرای دستی یک منبع
- مشاهده کیفیت و تازگی داده‌ها
- فعال یا غیرفعال کردن منبع

## محدوده نسخه اول

- حداقل دو منبع داده
- مدل استاندارد آگهی شغلی
- ذخیره داده خام و داده نرمال‌شده
- حذف تکراری‌های پایه
- API جست‌وجو و جزئیات
- داشبورد جست‌وجو و فیلتر
- زمان‌بندی جمع‌آوری
- logging، health check و ثبت خطا

## خارج از محدوده نسخه اول

- سیستم پیشنهاددهی مبتنی بر هوش مصنوعی
- ارسال خودکار درخواست استخدام
- شبکه اجتماعی کاربران
- پرداخت و اشتراک پولی
- اپلیکیشن موبایل native

## نیازمندی‌های غیرعملکردی

- پردازش جمع‌آوری نباید به API عمومی وابسته باشد.
- اجرای دوباره یک batch نباید رکوردهای تکراری ایجاد کند.
- خطای یک منبع نباید منابع دیگر را متوقف کند.
- API باید pagination و محدودیت نرخ درخواست داشته باشد.
- تمام زمان‌ها با UTC ذخیره شوند.
- اطلاعات حساس در کد یا لاگ ذخیره نشوند.
- آگهی‌های قدیمی و منقضی از نتایج پیش‌فرض حذف شوند.

## معیارهای موفقیت نسخه اول

- اضافه کردن منبع جدید بدون تغییر در منطق جست‌وجو ممکن باشد.
- وضعیت هر اجرای collector قابل مشاهده باشد.
- آگهی تکراری با احتمال بالا در سطح منبع و بین منابع شناسایی شود.
- جست‌وجوی معمولی در محیط production پاسخ قابل‌قبولی داشته باشد.
- داده خام برای بررسی خطا و بازپردازش نگهداری شود.
